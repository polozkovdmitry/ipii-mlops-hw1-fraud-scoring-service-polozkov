# Данные для обучения (необязательно)

Сюда можно положить полный `train.csv` (формат: колонки test.csv плюс `target`). В git файл не попадает (145 МБ, см. .gitignore).

Если файла нет, переобучение использует `misc/train_sample.csv.gz`, уменьшенную копию (случайные 20% строк с сохранением доли фрода), которая лежит в репозитории. Если файл есть, берётся он.

В docker-compose обе папки монтируются в контейнер fraud_detector только для чтения (`./data:/data:ro`, `./misc:/misc:ro`).
Чтобы обучить модель на новых данных, достаточно заменить `train.csv` здесь.
