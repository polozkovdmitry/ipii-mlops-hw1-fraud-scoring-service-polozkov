# Данные для обучения

Положите сюда `train.csv` (формат: колонки test.csv плюс `target`). В git файл не попадает (145 МБ, см. .gitignore).

В docker-compose папка монтируется в контейнер fraud_detector только для чтения (`./data:/data:ro`),
оттуда модель переобучается по кнопке в интерфейсе. Чтобы обучить модель на новых данных, достаточно заменить файл.
